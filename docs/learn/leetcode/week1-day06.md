## 题目

**[238. Product of Array Except Self（除自身以外数组的乘积）](https://leetcode.cn/problems/product-of-array-except-self/)**

给定整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的**乘积**。

要求：**O(n) 时间**，且 **不使用除法**；常数级额外空间（输出数组不计入）。

---

## 模式名

**前缀积 + 后缀积** — 一遍从左累乘得前缀，一遍从右累乘得后缀，或先输出数组存前缀再乘后缀。

## 暴力与目标复杂度（5min）

| 方法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 每位单独乘 | O(n²) | O(1) | 暴力 |
| 总乘积 + 除法 | O(n) | O(1) | **禁**；且多零失效 |
| **前缀 + 后缀** | **O(n)** | **O(n)** 或 **O(1)** extra | **目标** |

**目标：O(n) 时间，O(1) 额外空间**（不含输出数组）。

## 编码要点（35–40min）

**推荐：output 数组两遍扫（NeetCode 标准解）：**

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];

        ans[0] = 1;
        for (int i = 1; i < n; i++) {
            ans[i] = ans[i - 1] * nums[i - 1];
        }

        int suffix = 1;
        for (int i = n - 1; i >= 0; i--) {
            ans[i] = ans[i] * suffix;
            suffix *= nums[i];
        }
        return ans;
    }
}
```

**第一遍：** `ans[i]` = `nums[0..i-1]` 的积  
**第二遍：** 乘上 `nums[i+1..n-1]` 的积（用 `suffix` 滚动）

**检查点：** 不用 `/`；零元素用例手算通过。
